## Introduction
The purpose of this repository is to document and share solutions to problems from LeetCode. These solutions are written in multiple programming languages and demonstrate various algorithms and data structures.

## Organization
The solutions are organized by problem number and name:

```
Solutions/
├── 0001.Two_Sum.py
├── 0002.Add_Two_Numbers.cpp
├── 0003.Longest_Substring.java
├── 0004.Median_of_Two_Sorted_Arrays.js
└── ...
```

Each file is named using the format `<problem_number>.<short_description>.<extension>`.

## How to Use
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/leetcode-solutions.git
   ```

2. Navigate to the directory and locate the solution file by problem number.

3. Run the solution in the appropriate environment for the language (e.g., Python interpreter, C++ compiler, etc.).
